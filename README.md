# Sitio de prueba del ciclo 3 de FARO

Páginas con defectos de accesibilidad plantados a propósito, para ejecutar el ciclo 3 de pruebas
de FARO (`context/pruebas/plan_de_pruebas_ciclo_3.md` en faro-ecosystem). **No es un sitio real.**

Se publica con GitHub Pages en la raíz (`<organización>.github.io`): la ruta de cada URL coincide
con la ruta del archivo en el repositorio, que es lo que necesita el worker para ubicar cada
arreglo (faro-worker#146).

`casos.json` dice qué casos usa cada página y qué reglas tiene que detectar el motor.

URL base con la que se generaron las imágenes absolutas de las páginas de IA: `https://faro-ciclo3-org.github.io`.
